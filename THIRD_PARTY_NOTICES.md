# Third-party notices

Bring Vene uses maintained packages pinned in `pnpm-lock.yaml` and `uv.lock`. The installed dependency license inventory is retained in [licenses/dependencies.json](licenses/dependencies.json). Regenerate it after dependency changes with `node scripts/dependency-notices.mjs`.

## Adapted source

The lifecycle structure in `services/backend/src/bring_vene/voice/supervisor.py` is adapted from LiveKit Agents' `examples/other/transcription/multi-user-transcriber.py` at commit `b58e83f5c77d5b4bd4c8586793885151a91c4c83`, licensed under Apache-2.0. The implementation replaces startup and drain behavior with per-track consent checks and cancellation-safe ownership, and removes transcript logging and automatic shared transcription.

The upstream license and attribution notice are retained in:

- [LIVEKIT_AGENTS_LICENSE](services/backend/src/bring_vene/voice/licenses/LIVEKIT_AGENTS_LICENSE)
- [NOTICE](services/backend/src/bring_vene/voice/licenses/NOTICE)

[reuse-manifest.json](reuse-manifest.json) records the upstream source, exact commit and adaptations. Documentation and examples consulted without copying application source are separately identified there.

## Installed dependencies

The application uses Next.js, React, FastAPI, Pydantic, SQLAlchemy, Alembic, psycopg, OpenAI's Python SDK, LiveKit SDKs and the maintained Cartesia plugin as dependencies, under their respective upstream licenses. Their license terms are not replaced by this file.

pypdf is an installed BSD-3-Clause dependency, rather than copied parser source. Its retained license text is in [licenses/PYPDF_LICENSE](licenses/PYPDF_LICENSE). The application adds its own bounded subprocess adapter.

## Local tools and fixtures

Official LiveKit release archives are pinned by URL and SHA-256 in `infra/livekit-binary.json`. The Windows PostgreSQL archive from EDB is pinned in `infra/postgres-binary.json`; extracted server and command-line license files remain with the local tools. These downloaded binaries live under ignored `.local/` and are not redistributed as repository source. The hosted container installs its tools through the package managers specified in `deploy/Dockerfile`.

Tone WAVs are generated by `scripts/generate-audio-fixtures.py`. Spoken fixtures use original fictional wording and the locally installed speech engine; no voice model or recorded patient audio is included. The fictional PDF was authored with ReportLab and rendered with Poppler as authoring tools, not application runtime dependencies.
